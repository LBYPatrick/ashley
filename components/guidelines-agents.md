# Multiple Agents

Apply these rules to every task type when agent tools are available.

1. Check whether multiple agents can complete the task faster with good quality.
2. Prefer multiple agents when the task has enough independent work to benefit from parallel work.
3. Split work by business domain. Give each agent a clear scope, expected result, and file ownership.
4. Keep dependent work in sequence. Prevent agents from changing the same files at the same time.
5. Collect all agent results before final verification.
6. Check the combined changes and run the required tests and build.
7. Correct integration problems and verify the fixes before you report completion.

The main agent owns integration, final verification, and the completion report.
